## Problem

This project is the base for developing web-component SPAs.

## Users

- The author, as developer, adding components and composing new apps.

## Value proposition

Source is TypeScript, plain CSS and HTML templates; the build produces plain files that any simple web server can serve; data is a JSON file.

## Non-goals

- Server-side rendering or any backend beyond static file serving.
- A UI framework.
- Hot reloading; a manual browser refresh is acceptable.
- Editing the book data through the UI.
