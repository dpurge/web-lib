# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

### Added

- Project scaffold: TypeScript and plain CSS built by esbuild into `dist/`, a local static server (`npm run serve`) and tests (`npm test`).
- `bookshelf` app: books from a JSON file shown as cards with cover, text and book, PDF and audio links, with the data validated on load and errors shown on the page.
- Tab interface with one tab per shelf, keyboard navigation, a sticky wrapping tab bar, and the selected shelf kept in the URL hash.
- Light and dark theme toggle: follows the device setting until a choice is made, then remembers the choice in the browser; the dark palette meets a 4.5:1 text contrast ratio.
- Synthetic sample data and covers, regenerated by `npm run sample-data`.
- `npm run serve -- <port> 0.0.0.0` to open the server to the local network, for trying the app on a tablet.
